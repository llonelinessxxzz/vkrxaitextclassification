# vkrxaitextclassification

Graduation qualification project on text classification error analysis using XAI methods.

## Dataset

RuReviews

## Project structure

- `data/` — raw, interim and processed data
- `src/` — core system code
- `notebooks/` — experiments, tests, visualizations and examples
- `reports/` — figures, tables and generated reports
- `checkpoints/` — saved model weights

## Planned components

- text preprocessing
- baseline LSTM model
- RuBERT fine-tuning
- error corpus extraction
- error taxonomy construction
- LIME / SHAP / Captum analysis
- weak zone visualization
